01

Introducción

Fashion Light System es una propuesta de sistema web orientada a apoyar la administración de una tienda de ropa. El proyecto busca centralizar información relacionada con los productos, el inventario y las ventas, reduciendo la dependencia de registros manuales.

Desde el frontend se proporciona una interfaz organizada para que el usuario pueda consultar el inventario, revisar las características de las prendas, registrar ventas y consultar el historial de operaciones.

La implementación utiliza HTML para la estructura de las páginas, CSS para la presentación visual y JavaScript para incorporar comportamientos interactivos y validaciones del lado del cliente.

02

Objetivo

Desarrollar una interfaz web funcional, organizada y usable para apoyar la gestión de productos, inventario y ventas de una tienda de ropa mediante Fashion Light System.

El frontend busca facilitar la interacción del usuario con las diferentes funcionalidades del sistema, presentando la información de forma clara y proporcionando mecanismos de navegación y validación adecuados.

03

Alcance del proyecto

El proyecto contempla una interfaz para consultar y gestionar información relacionada con prendas de vestir y operaciones de venta.

  • Visualización del panel principal.
  • Consulta de productos del inventario.
  • Filtrado de productos por talla.
  • Registro, edición y eliminación de productos con carga opcional de imagen.
  • Registro de ventas.
  • Consulta del historial de ventas.
  • Visualización de un tutorial de uso.
  • Documentación de los componentes frontend.
  • Integración con PHP y MySQL para las operaciones de datos.

La solución está planteada como un proyecto académico y puede ampliarse posteriormente con autenticación, reportes más avanzados, gestión completa de usuarios y otras funcionalidades administrativas.

07

Funcionalidades JavaScript

El archivo js/funciones.js concentra las funcionalidades interactivas del frontend. El código se mantiene separado del HTML para facilitar el mantenimiento y reutilización.

  • Apertura y cierre del menú responsive mediante el botón de navegación.
  • Filtrado de los productos del inventario por talla.
  • Cálculo automático del subtotal en el formulario de venta.
  • Validación de campos requeridos antes de enviar una venta.
  • Confirmación del usuario antes de registrar la operación.
  • Formateo de valores monetarios para mejorar la lectura.
  • Marcación visual de campos que presentan errores.
  • Actualización de la imagen del producto seleccionado en el formulario de venta.

09

Relación con backend

Aunque este documento se concentra en los componentes frontend, Fashion Light System integra PHP y MySQL para gestionar la información persistente del sistema.

El formulario de registro de ventas utiliza venta.php para presentar los productos disponibles y recopilar los datos de la operación. Posteriormente, guardar_venta.php procesa la información enviada mediante POST.

La conexión con la base de datos se centraliza en conexion.php. El backend consulta el precio real del producto, calcula el total, registra la venta y actualiza el stock correspondiente. El formulario de inventario envía los datos mediante multipart/form-data a guardar_producto.php, que valida la imagen, la almacena en la carpeta img y registra su ruta en la tabla de productos.

De esta manera, el frontend facilita la interacción del usuario mientras que PHP y MySQL se encargan del procesamiento y almacenamiento de la información.

10

Conclusión

Fashion Light System integra diferentes componentes frontend para proporcionar una interfaz organizada y orientada a la gestión de una tienda de ropa.

La utilización conjunta de HTML, CSS y JavaScript permite construir páginas estructuradas, adaptables e interactivas. Además, la integración con PHP y MySQL permite conectar la interfaz con las operaciones de persistencia de datos.

El resultado constituye una base funcional para continuar ampliando el sistema con nuevas características administrativas y de gestión, manteniendo como principios la claridad, usabilidad, accesibilidad y organización de la información.
