Fashion Light System

Sistema web básico para la gestión del inventario y las ventas del almacén Fashion Light. La aplicación permite consultar productos, controlar existencias, registrar ventas y revisar el historial de operaciones.

Propósito del sistema

Fashion Light System busca apoyar la digitalización de las operaciones básicas del almacén Fashion Light. El sistema centraliza la información de los productos y las ventas, facilitando el control de las existencias y reduciendo la dependencia de registros manuales.


La solución está planteada como una aplicación web académica desarrollada con HTML, CSS, JavaScript, PHP y MySQL, ejecutada localmente mediante XAMPP.
