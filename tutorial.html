Tutorial para gestionar Fashion Light System

Aprende a consultar el inventario, registrar prendas con imagen, controlar existencias, registrar ventas y revisar el historial de operaciones.

1

Consultar el inventario

Abra Inventario desde el menú principal. Allí se muestran las prendas registradas junto con su imagen, nombre, marca, talla, color, precio y stock disponible.

Esta vista permite conocer rápidamente qué productos están disponibles antes de atender una venta o registrar una nueva prenda.

2

Registrar una prenda con imagen

En la página de inventario encontrará el formulario Registrar producto. Complete nombre, marca, talla, color, precio y stock. El campo de imagen permite adjuntar una fotografía en formato JPG, PNG o WEBP de máximo 5 MB.

Después de seleccionar Guardar producto, el sistema valida los datos, almacena la imagen y agrega la prenda al inventario. Para modificar una prenda existente, seleccione Editar, ajuste sus datos y presione Actualizar producto.

La opción Eliminar solicita confirmación. Un producto relacionado con una venta no puede eliminarse, porque el historial debe conservar sus referencias.

3

Filtrar y revisar existencias

Use el selector Filtrar por talla para mostrar únicamente prendas XS, S, M, L o XL. Seleccione “Todas las tallas” para regresar al catálogo completo.

Revise la columna Stock: las existencias bajas se identifican visualmente para apoyar la decisión de reposición. El stock también se verifica antes de guardar una venta.

4

Registrar una venta

Entre en Registrar venta y seleccione una prenda disponible. El listado muestra marca, talla, color y stock para ayudarle a elegir correctamente.

Indique una cantidad mayor que cero y complete el nombre y documento del cliente. Si el producto tiene una imagen registrada, esta aparece como referencia durante el registro.

5

Confirmar y guardar la operación

El subtotal se calcula automáticamente con la fórmula:

Subtotal = precio × cantidad

Revise el producto, la cantidad, los datos del cliente y el valor mostrado. Al enviar el formulario, confirme la operación. PHP valida nuevamente el producto y el stock antes de registrar la venta y descontar las unidades disponibles.

Venta lista para confirmar Producto, cantidad y subtotal verificados.
6

Consultar el historial de ventas

Abra Historial de ventas para consultar las operaciones almacenadas. Allí puede revisar el identificador, la fecha, el usuario y el total de cada venta registrada.

Esta consulta sirve para hacer seguimiento a las operaciones de la tienda y comprobar que los registros fueron guardados correctamente.

Ver historial ↑ Volver al contenido
Recomendación: revise siempre el stock y el subtotal antes de confirmar una venta. Las imágenes ayudan a identificar la prenda, pero los datos definitivos se validan en el servidor.

Conclusión

Fashion Light System reúne en un mismo flujo el registro de productos, la consulta del inventario, el control de existencias, el registro de ventas y el seguimiento de operaciones. Estas funciones permiten trabajar con información más organizada y reducir errores en la gestión diaria de la tienda.
